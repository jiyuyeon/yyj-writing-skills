# yyj-writing-skills

> Claude의 주절주절 버릇을 잡아주는 문서 작성용 Claude Code 스킬 모음.

- Claude는 한국어 문서를 쓸 때 줄글로 길게 풀고, 막연한 형용사를 쓰고, 출처 없이 수치를 단정하는 버릇이 있다.
- 이 repo의 스킬은 그 버릇을 슬래시 명령 한 번으로 점검하고 고쳐준다.
- 대상은 한국어 가공 산출 문서 — PRD(제품 요구사항 정의서), 리서치, 회의록, 요약 등.

## 수록 스킬

| 스킬 | 호출 | 하는 일 |
|---|---|---|
| `yyj-doccheck` | `/yyj-doccheck [파일경로] [--fix]` | 아래 8개 규칙 위반을 점검하고 수정안을 제시. `--fix`를 붙이면 본문에 바로 반영 |

## 점검하는 규칙 8가지

> 표 읽는 법: "이런 문장을 쓰면(위반 예) → 이렇게 바꾼다(수정 예)".

| # | 규칙 | 위반 예 | 수정 예 |
|---|---|---|---|
| 1 | 막연한 형용사·부사 금지 | "데이터가 풍부하다" | "공개 출처 4종 + 실거래가 API — 2024 기준" |
| 2 | 출처 없는 수치 금지 | "80% 파악" | "80% 파악 (자체 추정 — 검증 전, `가정:` 라벨)" |
| 3 | 단정어 금지 | "당연히 수요가 있다" | "수요 추정 — 근거: ... / 한계: 표본 5명" |
| 4 | 확증편향 점검 | 결론에 유리한 근거만 나열 | 반대 증거 1개 이상 + `데이터:`·`판단:`·`가정:` 라벨 구분 |
| 5 | 에세이형·질문형 제목 금지 | "이 문서가 답하려는 질문" | "개요" (명사구로) |
| 6 | 용어집 섹션 금지 | 문서 끝에 "## 용어 정리" 모음 | 첫 등장 자리에 괄호 설명: "라이선스(정부 허가 — 자본금·심사 동반)" |
| 7 | 풀어쓰지 않은 약어 금지 | "MVP부터 만든다" | "MVP(최소 기능 제품)부터 만든다" |
| 8 | 줄글 단락 금지 | "A다. 그리고 B다. 따라서 C다." | `- A` / `- B` / `- C` 로 분해 + 결론에 요약표 동반 |

- 규칙 1·2·3·5·6·7은 `grep`으로 자동 탐지한다.
- 규칙 4·8은 자동 탐지가 안 되므로 본문을 읽고 판단한다.
- 검사 안 함: 비정제 원본(대화 메모, 인터뷰 raw). 원형 보존이 목적이라 규칙 미적용.

## 설치

- Claude Code는 `~/.claude/skills/` 안의 스킬을 자동 인식한다.
- 이 repo를 clone한 뒤 스킬을 그쪽으로 심볼릭 링크하면 끝.

```bash
# 1. 원하는 위치에 clone
git clone https://github.com/jiyuyeon/yyj-writing-skills.git ~/yyj-writing-skills

# 2. 스킬을 ~/.claude/skills 로 링크
ln -s ~/yyj-writing-skills/skills/yyj-doccheck ~/.claude/skills/yyj-doccheck

# 3. Claude Code 재시작 → /yyj-doccheck 사용 가능
```

- 링크 방식: `git pull`로 받은 업데이트가 즉시 반영된다.
- 복사 방식: 링크가 번거로우면 폴더째 복사한다. 단 업데이트마다 다시 복사해야 한다.

```bash
cp -R ~/yyj-writing-skills/skills/yyj-doccheck ~/.claude/skills/yyj-doccheck
```

## 업데이트

```bash
cd ~/yyj-writing-skills && git pull
```

- 링크로 설치했다면 그걸로 끝.
- 복사로 설치했다면 위 `cp` 명령을 다시 실행한다.

## 새 스킬 추가

- `skills/<스킬이름>/SKILL.md` 형식으로 폴더를 추가한다.
- 폴더명과 `SKILL.md`의 `name:` 필드가 일치해야 인식된다.

```
skills/
  yyj-doccheck/
    SKILL.md
  yyj-<다음스킬>/
    SKILL.md
```
